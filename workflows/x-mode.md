# X Mode — Vertical Visual Narrative

## Output

A sequence of **9:16 vertical mobile images** that tells the story through high-end visual storytelling.

Allowed visual modes:
- X-PHOTO — cinematic photography / photoreal stills
- X-REALISM — realistic illustration / concept-art finish
- X-COMIC — realistic adult graphic-novel / cinematic comic language

Avoid defaulting to anime or low-detail cartoon language.

## Narrative design

Do not mechanically make one image per screenplay shot.

First create an X page/frame plan based on reading rhythm and dramatic beats.

An X frame may be:
- one full-page cinematic image
- split composition
- 2–4 panel comic page
- foreground/background narrative composition
- controlled montage
- visual reveal page

Choose the presentation method because it improves the story, not because of a fixed template.

## Text

Plan:
- dialogue
- narration
- captions
- diegetic text when necessary

First-pass generation may include the real dialogue/narration so image and typography are designed together.

If exact text is wrong:
1. image edit
2. if still unreliable, deterministic typography repair while preserving the accepted design.

## X Frame contract

Each frame defines:
- narrative_function
- source_beat
- aspect_ratio = 9:16
- visual_mode
- composition
- characters
- location
- action
- expression
- dialogue
- narration
- continuity
- reference_assets
- generation_notes
