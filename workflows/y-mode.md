# Y Mode — Seedance Live-Action Film Production

## Non-negotiable visual policy

Final master: **21:9 horizontal**.

Y is:
- live-action
- photorealistic
- cinematic
- realistic VFX when needed

Y is not:
- comic
- anime
- illustrative animation
- 3D-animation look

Storyboard and production keyframes should also respect the live-action direction.

## Production outputs

Y must prepare more than prompts.

Create:
- locked screenplay / scene script
- production script
- shot list
- shot purpose
- shot size
- camera angle
- lens intent
- camera movement
- actor blocking
- action
- performance / expression
- dialogue
- VO / narration
- ambience
- Foley
- SFX
- music intent
- transitions
- lighting
- production design
- VFX notes
- continuity
- character pack
- scene pack
- prop pack
- story-preview storyboard
- production keyframes
- Generation Units
- reference maps
- Seedance prompts
- generation review plan
- edit / extend / regenerate plan
- editorial timeline
- final QC

## Shot vs Generation Unit

Shot = director/editor planning unit.

Generation Unit (GU) = AI generation unit.

One GU may contain one shot or several logically connected shots.

Split a GU when:
- continuity becomes unstable
- too many subjects/actions compete
- location/time changes
- precise dialogue timing becomes difficult
- a critical keyframe needs independent control

## Seedance prompt

Keep it operational.

Prefer:
duration + ratio + references + action progression + camera behavior + dialogue/audio intent.

Do not duplicate all Story Master prose in every prompt.

## Audio

Treat audio as a first-class production layer:
- character voice references
- dialogue
- VO
- ambience / room tone
- Foley
- designed SFX
- music
- purposeful silence

## Revision

KEEP — accepted.
EDIT — preserve clip, modify a specific item.
REGENERATE — clean rerun from canonical anchors.
EXTEND — continue accepted video.
COMPOSITE — separate VFX/layer solution when one-pass generation is unreliable.
