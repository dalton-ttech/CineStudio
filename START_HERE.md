# Start Here

## Use with Codex or another local agent

Clone this repository and open it as the working repository.

Then tell the agent:

> Read AGENT_BOOTSTRAP.md and WORKFLOW.md. Use the CineStudio workflow to create a new local project from my supplied source file. Do not create a global AGENTS.md. Ask me to choose X or Y only if I have not already specified the mode.

You can also paste the GitHub repository URL to an agent and say:

> Read CineStudio's START_HERE.md and AGENT_BOOTSTRAP.md from this repository. Recreate the required local project structure and follow the workflow.

## Modes

- X = 9:16 vertical visual narrative.
- Y = 21:9 horizontal live-action cinematic production for Seedance 2.5.

## Recommended first run

1. Supply a source file.
2. Create Story Master.
3. Choose adaptation permission: strict / expand / adapt.
4. Produce a small Lookboard and story-preview Storyboard.
5. Approve visual direction.
6. Continue into X or Y.

Do not generate the whole project before the relevant approval gates are passed.
