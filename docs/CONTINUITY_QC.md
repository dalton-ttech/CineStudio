# Continuity QC

Check continuity at three levels.

## Story
- cause/effect
- chronology
- dialogue facts
- object state
- character knowledge

## Visual
- face / age / hair
- costume / accessories
- handedness
- props
- location layout
- time of day
- lighting direction
- weather
- wounds / dirt / damage state

## Film
- screen direction
- eyelines
- entry/exit direction
- shot-size progression
- camera continuity
- opening/closing state between Generation Units
- audio ambience continuity

Failed generations do not become continuity anchors automatically.
