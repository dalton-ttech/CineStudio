# Story Master

Story Master is the canonical continuity layer for both X and Y.

Required sections:
- metadata
- adaptation_mode: STRICT / EXPAND / ADAPT
- logline
- synopsis
- theme
- beat_sheet
- characters
- relationships
- scenes
- props
- timeline
- key_dialogue
- visual_reveals
- continuity_rules
- locked_facts
- open_decisions

Story Master is not a prompt. It is production truth.

Once a fact becomes LOCKED, downstream workers should not reinterpret it without an explicit revision.
