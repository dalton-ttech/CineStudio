# Source Ingestion

Treat supplied files as the authority for source-derived facts.

Extract:
- title / premise
- story events
- characters
- locations
- props
- dialogue
- chronology
- explicit visual direction
- existing shot information
- sound/music notes
- constraints

Mark each item as:
- SOURCE — explicitly supported by source material
- PROPOSED — CineStudio adaptation / production suggestion
- LOCKED — approved by the user and now canonical

Do not silently repair contradictions. Surface them as open decisions.

Preserve source terminology where possible.
