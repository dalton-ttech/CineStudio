# Versioning

CineStudio uses semantic versioning.

VERSION contains the current release number.

Commit/release convention:
- v0.1.0 — initial usable workflow
- patch — fixes that do not materially change workflow contracts
- minor — new workflow capabilities / templates
- major — incompatible workflow or project-layout changes

Release branch format:
release/vX.Y.Z

Preferred release commit:
release: CineStudio vX.Y.Z

Update CHANGELOG.md with each release.
