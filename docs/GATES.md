# Approval Gates

CineStudio should stop at meaningful creative gates instead of producing everything blindly.

1. Story Lock — story structure and adaptation direction accepted.
2. Look Lock — visual direction accepted.
3. Storyboard Lock — narrative visualization accepted.
4. Anchor Lock — character / scene / prop anchors accepted.
5. Keyframe Lock — Y only; production keyframes accepted.
6. Generation — produce X frames or Y Generation Units.
7. Final QC — continuity, copy, audio, and delivery checks.

A user may explicitly skip a gate.
